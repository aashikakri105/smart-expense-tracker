# 💰 Smart Expense Tracker

A simple and user-friendly web-based expense management application built with Python and Flask. It allows users to manage daily expenses, track monthly spending, analyze expenses by category, and export expense data.

## 🚀 Features

- ➕ Add new expenses
- 👀 View all expenses
- ✏️ Update existing expenses
- 🗑️ Delete expenses
- 🔎 Search expenses by name
- 🏷️ Filter expenses by category
- 📅 Track expenses by date
- 💰 Set and monitor monthly budget
- 📊 View total and monthly spending
- 🥧 Pie chart for category-wise expenses
- 📊 Bar chart for spending analysis
- 📥 Export expenses to CSV
- 🌐 Browser-based user interface

## 🛠️ Technologies Used

### Backend
- Python
- Flask

### Database
- SQLite

### Frontend
- HTML
- CSS
- JavaScript

### Data Visualization
- Chart.js
